---
title: Uninstall
description: Remove the Southbag Code package.
---

Use the same package manager that installed Southbag Code:

```bash
npm uninstall -g @southbag/code
pnpm remove -g @southbag/code
yarn global remove @southbag/code
bun uninstall -g @southbag/code
```

Configuration and sessions may remain behind.
